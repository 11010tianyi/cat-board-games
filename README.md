# 猫猫棋局

黑色黄眼睛短毛田园猫和白色淡黄眼睛长毛田园猫主题的 SVG 下棋游戏合集。

## 玩法

- 五子棋：15 路连五。
- 围棋：9 路简化吃子规则，支持停着和提子计分。
- 象棋：双猫阵营的中国象棋，包含车马炮兵等走法。
- 跳跳棋：双猫对角跳跃，可连跳。
- 大富翁：双猫掷骰、买地、收租。

## 本地运行

```bash
bun install
bun run dev
```

## 构建

```bash
bun run build
```

GitHub Pages 会在 `main` 分支推送后自动部署到：
